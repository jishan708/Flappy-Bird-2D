# Flappy Bird 🐦

A simple 2D Flappy Bird-style game developed using **Unity and C#**.

## Features

* Bird flap and movement
* Random pipe generation
* Scrolling background/ground
* Score system
* Game Over screen
* Restart functionality
* High score system

## Built With

* Unity
* C#
* Unity 2D Physics
* TextMeshPro

## How to Play

* **Click / Tap** to make the bird fly.
* Avoid the pipes.
* Try to get the highest score possible.

## Project

This project was created to practice **Unity 2D game development, C# scripting, physics, UI, and game mechanics**.
